# 0011. 레이아웃: 헤더/하단 띠(A) + 대화 타임라인(C)

상태: 채택 (2026-10-24)

## 배경

- 제목: 범위, 개수, 경로가 같은 흐린 색 한 줄에 이어져 경계가 보이지 않았다. 대화 제목 옆에는 `role:all tools` 같은 내부 표기가 붙었다.
- 본문: 메시지 구분이 `▌ You`/`▌ Claude` 헤더 한 줄뿐이라 긴 대화에서 프롬프트 경계가 묻혔다.
- 네비게이션: 상태줄 하나에 위치, 키 힌트, 일시 메시지가 번갈아 들어가고 힌트가 문장처럼 길었다.

시안 네 가지(A 정돈된 크롬, B 패널 분할, C 대화 타임라인, D 탭과 모드라인) 중 A 의 헤더/하단과 C 의 본문/목록을 합쳤다.
참고: lazygit·bubbles/help 의 문맥별 키 힌트, Claude Code·Crush·opencode 의 대화 표식, telescope·gh-dash 의 2줄 항목과 묶음.

## 결정

- 상단 헤더 띠(`chrome.lis` `header_bar`): reverse 배지 ` cci ` + 위치(목록: `범위 › cwd`, 대화: `세션 › 제목`), 오른쪽에 요약
  (목록: 세션 수, 대화: 시작~끝 시각). 좁으면 왼쪽부터 `…` 로 줄인다.
- 하단 띠(`footer`): 왼쪽은 키 힌트(키 굵게, 설명 흐리게, 들어가는 만큼만), 오른쪽은 위치와 모니터링 상태로 자리를 고정한다.
  상태 메시지와 검색 상태는 왼쪽 힌트 자리에 들어가고 오른쪽 상태는 그대로 남는다.
- 목록: 날짜 묶음(오늘, 어제, 최근 7일, 그 이전은 월)과 2줄 항목. 묶음과 오른쪽 시각은 정렬 기준인 파일 수정 시각(mtime)을 쓴다(0012).
  항목은 제목 + 오른쪽 시각 / 브랜치 · 메시지 · 프롬프트 · 전체 범위면 cwd.
  선택 항목은 `┃` 표식 + 굵은 제목 + 옅은 바탕. 폭 60 미만이거나 `--compact` 면 1줄 항목.
  스크롤 `top` 은 항목이 아니라 줄 단위이고, 묶음의 첫 항목이면 묶음 제목도 보이게 맞춘다. 페이지 이동은 화면에 들어가는 항목 수 단위.
- 대화 헤더 둘째 줄: 브랜치 · cwd · 메시지 수 · 프롬프트 수, 오른쪽에 기본과 다른 보기 설정만(역할, 도구, thinking, 코드, 펼침, 디버그).
  `--compact` 면 헤더 두 줄을 생략한다.
- 대화 본문(Claude Code 표식을 따름):
  - 프롬프트: 옅은 바탕 블록, 첫 줄 `›` 와 오른쪽 시각.
  - 응답 텍스트와 도구 호출: `●`(응답은 assistant 색, 도구는 tool 색). 코드 변경은 `● Edit 경로  +3 -1` 아래 diff.
  - 도구 결과: `⎿`(오류는 `✗`). 결과만 담은 user 메시지는 앞 조각에 빈 줄 없이 붙인다(`attaches_to_previous`, `tight`).
  - thinking `✻`, 메타 `⋯`. 표식은 블록 첫 줄의 앞 두 칸을 쓰고 본문은 두 칸 들여쓴다.
  - 앞 메시지와 5분 이상 떨어진 프롬프트 앞에 `── 15:04 ──` 구분선(날짜가 바뀌면 날짜 포함). 구분선은 캐시 밖에서 붙인다.
  - 응답 첫 줄 오른쪽에도 시각을 둔다(glamour 가 채운 뒤쪽 공백은 걷어 낸다). 폭 60 미만이면 시각을 생략한다.
- 오른쪽 1열 스크롤바: 손잡이 `┃`, 길 `│`, 프롬프트 위치 `◆`. 내용이 한 화면에 들어오면 비운다. 본문 폭은 `width - 2`.
- 0004 의 compact `U`/`A` 역할 표시는 표식(`›`, `●`)으로 대체됐다.

## 색 없음과 좁은 창

- NO_COLOR/`--no-color`: 배지는 reverse, 선택은 `┃`, 프롬프트는 `›`, 응답은 `●` 로 남는다. 바탕색만 사라진다.
- 표식 `› ● ⎿ ◆ ┃` 는 East Asian Ambiguous 폭이다. 기존 `▌ │` 와 같은 전제(1칸)를 따른다.
