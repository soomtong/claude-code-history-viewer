# 0007. 필터, 토글, 코드 뷰, 검색 (Phase 3)

상태: 채택 (2026-10-22)

## 결정

- 역할 필터는 `r` 순환(all -> user -> assistant). `u`/`a`/`A` 는 쓰지 않는다(목록의 `a` 는 범위 전환).
- 표시 토글(대화 뷰): `t` 도구 호출 요약 + tool_result, `T` thinking, `c` 코드 변경, `e` 접힌 블록 펼치기,
  `D` 디버그(메타 텍스트, 알 수 없는 블록, 헤더에 unknown/broken 카운트).
- 코드 뷰는 오버레이 대신 메시지 안 인라인 토글로 구현했다. Write/NotebookEdit 은 내용, Edit/MultiEdit 은
  `-`/`+` 줄(빨강/초록)로 표시. 메시지 문맥 안에서 바로 보이는 편이 복기에 낫고 구현이 작다.
- 접기: tool_result 8줄, 코드 30줄(`RESULT_FOLD`, `CODE_FOLD`). 넘치면 "… N줄 더 있음 (e 로 펼치기)".
  긴 줄은 폭에 맞춰 자른다(코드/결과는 줄바꿈하지 않음).
- 보이는 메시지 규칙: 프롬프트나 텍스트가 있으면 항상, 그 외에는 켜진 토글에 해당하는 블록이 있을 때만.
- 검색(`/`): 타이핑 즉시 매치 갱신 후 현재 위치 이후 첫 매치로 점프, enter 확정, esc 해제(한 번 더 esc 면 목록).
  매치는 viewport 내용에서 ANSI 를 벗긴 줄 단위 부분일치(대소문자 무시). 하이라이트 치환은 하지 않고
  상태줄에 `[i/m]` 을 보인다. 검색 중에는 `n`/`N` 이 매치 이동, 아니면 메시지 이동(`]`/`[` 는 항상 메시지).
  숨겨진 블록(토글 꺼짐)은 검색 대상이 아니다. relayout 후 매치를 다시 계산한다.
- 목록 필터 대상: 제목, 첫 프롬프트, cwd, gitBranch, 시작/수정 날짜(`YYYY-MM-DD HH:MM` 로컬), 세션 id. 부분일치.
- 상태 메시지는 키 입력마다 초기화하고, 비어 있으면 키 안내를 보여준다.

## 검증

- `src/tui/features.test.lis`: 역할 순환, 토글별 표시 내용(ANSI 제거 후 비교), 접기, 검색(점프, n/N, 카운트, esc),
  목록 필터(브랜치, 날짜, cwd).
- tmux 수동 확인: `t`, `c` 토글 화면과 `/rename` 검색 상태줄.
